# pet_xiaoman · 色彩体系

> 版本 v1.0 · 2026-09-05 · graphic-design-guide（场景一裁剪版，第一轮 4/4）
> 从 PRD §5.6.3 临时视觉升级为正式品牌色。气质线：自然有机 · 情绪任务：安宁的陪伴者。

## 一、品牌色定义（三模式）

### 主色 · 暖松绿（占比 30%，品牌识别色）

| 模式 | 值 | 说明 |
|---|---|---|
| HEX | `#5B8C85` | 数字主用 |
| RGB | 91 / 140 / 133 | — |
| CMYK | 35 / 0 / 5 / 45 | 印刷用 |
| PANTONE | 5615 C（近似） | 印刷前必须打样校准，以实物色卡为准 |

- **情绪任务**：安宁的陪伴者——偏灰的沉静绿，不是环保宣传的鲜绿，也不是薄荷的轻快绿。它是"松林里的安静"。
- **用途**：logo 线条（反白场景）、主按钮、导航底色、tab 选中态。
- **色阶**：深松 `#3D5C57`（文字/描边）· 浅松 `#EEF4F3`（背景块）· 禁用 `#B9CFCB`（disabled 专用，不作装饰）
- **导航渐变**（设计规范 v1.1 §9.2）：`linear-gradient(180deg, #5B8C85 → #4A756E)`——顶部导航/状态头专用（高 96px），终点色即主色按压态，天然同源

### 辅色 · 暖陶土（占比 ≤10%，情绪刺点）

| 模式 | 值 | 说明 |
|---|---|---|
| HEX | `#D9A468` | — |
| RGB | 217 / 164 / 104 | — |
| CMYK | 0 / 52 / 52 / 15 | — |
| PANTONE | 157 C（近似） | 印刷前打样校准 |

- **情绪任务**：温暖的一次触摸——告别场景、纪念物、时间线节点的专属点缀色。**禁止用于促销、按钮、大面积背景**（它一多就从"刺点"变成"土黄"）。
- **色阶**：浅陶 `#F6EADB`（纪念场景背景）

### 中性色（占比 60%，呼吸空间）

| 名称 | HEX | 用途 |
|---|---|---|
| 纸感白 | `#FAF9F6` | 页面底色（纯白太冷，纸感白给温度） |
| 暖灰 | `#86909C` | 次级文字 |
| 深炭 | `#3B3F45` | 正文文字（**禁用纯黑 #000**，纯黑是殡葬感的第一来源） |

## 二、60-30-10 使用法则

```
60% 中性色（纸感白底 + 灰字）—— 留白与呼吸
30% 主色系（暖松绿 + 色阶）—— 品牌识别与操作
10% 辅色系（暖陶土 + 点缀）—— 情绪时刻专用
```

判断标准：任意一屏截图里，陶土色面积超过 20% 即违规；纸感白少于 40% 即违规（页面会闷）。

## 三、色彩禁忌（一票否决项）

1. **纯黑 `#000000`**——一律用深炭 `#3B3F45` 代替（殡葬感第一来源）
2. **冷蓝/藏青**——与安宁暖调冲突（科技感错位）
3. **高饱和促销红**（#FF0000 类）——情绪脆弱期的负资产；错误提示用砖红 `#D54941`
4. **荧光/高饱和绿**——品牌绿是"灰调松绿"，鲜绿是环保宣传、不是安宁陪伴
5. **紫色系**——无情绪任务，出现即删

## 四、应用速查（两场景）

**线上（当前）**：HEX 为准，RGB 输出，72 PPI；小程序/App/小红书同源。
**印刷（未来）**：CMYK 出稿 + PANTONE 5615C/157C 专色校准；纸张建议原色纸或哑膜（对齐自然有机质感），禁亮膜（反光破坏安宁感）；文字转曲、出血 3mm、安全区 5mm。

## 去AI味自检
- ✅ 不做决策：纯黑/冷蓝/促销红/荧光绿/紫色系五个禁区各有一条业务理由（情绪脆弱期用户），不是审美偏好
- ✅ 数字具体：60-30-10 配比、陶土面积 ≤20% 违规线、纸感白 ≥40% 底线、三模式色值全给
- ✅ 竞品立场：全行业自发避开黑白是隐式共识，我们是第一个把它写成显式禁忌清单的；主绿故意偏离"环保绿"抢占"安宁绿"心智
- ✅ 此刻合理性：PRD 已用临时色开发，本文档是收口定稿而非新起炉灶——避免品牌色二次漂移
- ✅ 优先级倾斜：主绿与纸感白承担 90% 的识别与呼吸任务，陶土被严格限制在 10% 情绪时刻——克制就是品牌
