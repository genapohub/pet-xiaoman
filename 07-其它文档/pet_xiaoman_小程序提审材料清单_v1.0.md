# pet_xiaoman_小程序提审材料清单_v1.0

> 日期：2026-09-13  
> 目的：为宠小满 V1.0 试运营准备微信小程序提审材料。  
> 原则：文案中性、服务真实、价格透明，不使用夸张营销和敏感表达。

---

## 一、提审口径

| 项 | 建议 |
|---|---|
| 产品名称 | 使用真实门店小程序名称；宠小满作为示例门店或品牌样板 |
| 服务定位 | 宠物告别 / 宠物善终 / 宠物火化服务预约 |
| 类目方向 | 生活服务相关类目，按微信开放平台实际可选类目最终确认 |
| 支付状态 | 商户号未就绪时关闭线上支付，仅保留到店付 |
| 数据口径 | 一套后端、多门店隔离；小程序按 slug 或默认门店进入 |

---

## 二、主体与资质材料

| 材料 | 状态 | 备注 |
|---|---|---|
| 营业执照 | 待准备 | 主体需与小程序主体一致 |
| 法人/管理员信息 | 待准备 | 按微信平台要求提交 |
| 经营场所证明 | 待准备 | 可用于增强审核可信度 |
| 动物无害化处理/相关经营许可 | 待确认 | 按当地合规要求准备 |
| 服务合作/授权材料 | 视情况 | 若有第三方火化/处置合作需准备 |

## 三、小程序基础资料

| 材料 | 要求 |
|---|---|
| 小程序名称 | 与门店或品牌一致，不使用夸张承诺 |
| 头像/logo | 清晰、无侵权、无医疗/殡葬夸张图形 |
| 简介 | 说明服务范围：预约、价格查询、订单进度、门店联系 |
| 服务区域 | 写真实城市/门店覆盖范围 |
| 客服电话 | 与门店资料一致 |

建议简介：

> 提供宠物告别服务预约、服务价格查询、订单进度查看与门店联系。价格公开透明，服务前由门店电话确认。

---

## 四、页面与功能检查

| 页面 | 审核关注点 | 提审前检查 |
|---|---|---|
| 首页 | 是否清楚说明服务，不夸大承诺 | 店名、电话、地址正确 |
| 价格表 | 是否明码标价 | 服务项、价格、版本说明完整 |
| 服务详情 | 是否说明服务流程 | 避免刺激性词汇和图片 |
| 预约下单 | 是否收集必要信息 | 隐私说明和门店确认逻辑清楚 |
| 收银台 | 支付未开时不能误导用户 | 到店付文案清晰 |
| 订单详情 | 是否展示真实进度 | 时间线和影像说明真实 |
| 个人中心 | 登录、资料、退出可用 | 承诺页、门店联系可访问 |
| 关于承诺 | 价格透明、过程可见 | 不写无法兑现的绝对化承诺 |

## 五、文案合规建议

### 推荐表达

- 宠物告别
- 宠物善终
- 服务预约
- 价格公开
- 服务前电话确认
- 订单进度可查看
- 单独服务 / 单独火化

### 谨慎或避免

- 绝对化承诺：100% 保证、全网最低、永不加价。
- 刺激性表达：遗体、尸体、棺材等用于营销场景的词。
- 夸张营销：限时抢购、爆款、秒杀。
- 无依据资质：官方指定、唯一认证、行业第一。

## 六、协议与政策

| 文档 | 状态 | 备注 |
|---|---|---|
| 用户服务协议 | 待准备 | 说明预约、取消、改期、服务确认 |
| 隐私政策 | 待准备 | 说明手机号、地址、宠物信息、影像用途 |
| 价格说明/透明定价声明 | 待准备 | 说明下单锁价、额外服务需确认 |
| 支付与退款说明 | 待支付开通后补 | V1.0 若仅到店付，可先说明到店结算 |
| 影像授权说明 | 建议准备 | 说明影像仅用于订单进度和服务记录 |

---

## 七、支付开关检查

| 场景 | 处理 |
|---|---|
| 商户号未开通 | `PAY_ENABLED=false`，C 端只展示到店付 |
| 商户号已开通 | 补齐商户号、私钥、APIv3 密钥、回调地址 |
| 回调域名未配置 | 不开启线上支付 |
| 退款流程未验证 | 不宣传“自动退款”，只写人工确认退款 |

---

## 八、提审前最终检查

- [ ] 小程序名称、logo、简介已确认。
- [ ] 真实门店电话、地址、营业时间已配置。
- [ ] 价格表与实际服务价格一致。
- [ ] 预约下单可以提交。
- [ ] 到店付或支付状态文案清楚。
- [ ] 用户协议、隐私政策、价格声明已准备。
- [ ] 页面无其他门店品牌残留。
- [ ] 页面无测试账号、测试手机号、测试地址。
- [ ] 图片无侵权、无刺激性内容。
- [ ] 后台可处理小程序提交的订单。

---

## 九、审核被拒后的处理

| 拒审原因 | 处理方式 |
|---|---|
| 类目不匹配 | 按微信平台建议调整类目或补资质 |
| 文案敏感 | 改为中性服务表达，删掉营销化词 |
| 支付能力不完整 | 关闭线上支付入口，仅保留到店付 |
| 隐私说明不足 | 补隐私政策与收集用途说明 |
| 页面不可用 | 先修复 P0，再重新提交 |
