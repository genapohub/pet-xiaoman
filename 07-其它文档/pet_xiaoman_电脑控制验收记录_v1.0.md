## 二、工具限制说明

电脑控制插件在微信开发者工具和 Chrome 上均遇到过系统级捕捉问题：

- 微信开发者工具：点击后自动观察阶段触发 macOS `ScreenCaptureKit` 捕捉错误。
- Chrome：通过电脑控制直接创建标签页时出现控制层请求失败。

处理方式：

- C 端：电脑控制成功读取了微信开发者工具页面树；截图阶段使用当前屏幕截图兜底，并通过页面路径确认当前为 `pages/order-create/index`。
- B 端：使用临时 Chrome 验收实例和真实后台登录接口抓图；该实例使用独立临时资料目录，不复用哥拿坡日常 Chrome 登录态。

因此，本轮结论可以覆盖“当前本机页面可见状态”，但不能替代微信真机预览的最终手感验收。
