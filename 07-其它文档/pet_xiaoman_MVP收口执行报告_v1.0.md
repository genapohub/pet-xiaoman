## 三、本轮修复

### 1. 修复 API 本地解释器环境

API 子项目 `.venv` 原本指向不存在的 Python 3.14 路径，导致 PyCharm 运行配置提示“找不到此运行配置的 Python 解释器”。已在当前机器重建 `06-项目编码/pet_xiaoman_api/.venv` 并按 `requirements.txt` 安装依赖，PyCharm 配置 `API FastAPI 8010` 可继续使用。

### 2. 增强启动脚本诊断

`06-项目编码/pet_xiaoman_api/scripts/start_dev_api.sh` 现在支持 `PYTHON_BIN` 覆盖，并能区分：解释器不存在、解释器链接失效、依赖缺失、端口占用四类问题。
