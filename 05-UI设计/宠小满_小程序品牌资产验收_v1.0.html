06 · 编译期踩坑（已修）

WXML 的绑定表达式不是 JavaScript，以下写法会在微信开发者工具编译期直接失败、导致整包白屏。
本地开发时肉眼看不出来，必须真的编译一次才会暴露。
错误写法后果正确做法
{{t.expect_time.slice(0,16).replace("T"," ")}}不支持函数调用JS 里预格式化 → utils/format.js 的 fmtTime()
{{!(groups[active] || []).length}}括号表达式后不能取成员JS 里算好 current 数组 → {{!current.length}}
{{o.created_at.slice(0,10)}}不支持函数调用fmtDate() 预格式化
{{x?.y}} / `${x}` / {{x => x}}可选链 / 模板串 / 箭头函数均不支持全部下沉到 JS
两层校验：① 静态 scripts/check-assets.py（秒级，查图片 404 + Token 未定义 + WXML 非法表达式）； ② 真编译 cli preview --project ...（约 8s，唯一能暴露编译错误的手段）。
