## 1. 设计定位：善终行业的设计母题

**行业两个极端都要避开**：传统殡葬的黑白灰（悲情、压抑、有距离感）；互联网医疗的冷蓝（医院感、工具感）。

**宠小满的设计母题：一场温柔的告别。**

| 情绪维度 | 设计表达 | 具体手法 |
|---|---|---|
| 安宁 | 低饱和、大留白、慢动效 | 页面背景不用纯白（#F7F8FA 暖灰），动效 2s 呼吸而非闪烁 |
| 温暖 | 暖色点缀、圆角、手作质感 | 暖陶土只出现在情感触点（告别/纪念），绝不用在功能按钮 |
| 庄重 | 克制的层级、不卖萌 | 不用 emoji 装饰、不用荧光色；图标线性细描 |
| 信任 | 透明可见 | 价格/影像/进度全部直给，不折叠不隐藏 |

**色彩立场声明**：主色暖松绿 `#5B8C85` —— 松 = 常青与安宁，绿 = 生命延续；替代色微信绿 `#07C160` 为什么不行：太"互联网产品"，缺乏告别场景的沉淀感；替代色黑白灰为什么不行：落回传统殡葬的压抑。暖陶土 `#D9A468` 为什么存在：告别是有温度的仪式（陶土/泥土/手作），它只服务情绪，不服务功能。

## 2. 情感节奏（用户旅程 × 页面情绪目标）

| 页面 | 用户情绪 | 设计目标 | 视觉强度 |
|---|---|---|---|
| C001 首页 | 焦虑 → 被接住 | 三秒内感到"这家店靠谱" | 强（品牌沉浸） |
| C002/C003 价格表 | 比价 → 安心 | 透明到无需追问 | 中（信息清晰） |
| C004 预约 | 悲伤中操作 | 步骤极简、错了能改 | 弱（零负担） |
| C005/C006 订单/时间线 | 牵挂 | 每个环节可见、可回看 | 中（安静呈现） |
| C007 纪念品 | 释怀中的思念 | 柔和不推销 | 中 |
| C008/C009/C010 | 日常 | 工具感即可 | 弱 |

**情感节奏铁律**：C004 预约页绝不能出现任何悲情元素（用户正悲伤中填表单）；C006 时间线的影像是整个产品的信任巅峰，必须安静呈现（无弹窗打断）。

## 3. Design Tokens（微信小程序 rpx 体系）

### 3.1 色彩 Token ↔ WXSS 变量映射表

| 设计 Token | WXSS 变量 | 值 | 用途 |
|-----------|----------|-----|------|
| Color/Brand/Primary | `--color-primary` | `#5B8C85` | 主按钮/选中态/时间线当前节点 |
| Color/Brand/Pressed | `--color-primary-pressed` | `#4A756E` | 按压态（button-hover） |
| Color/Brand/Disabled | `--color-primary-disabled` | `#B9CFCB` | 禁用态 |
| Color/Accent/Warm | `--color-accent` | `#D9A468` | 情感触点：告别节点/纪念品价格/纪念标签 |
| Color/Functional/Success | `--color-success` | `#2BA471` | 完成/正常 |
| Color/Functional/Warning | `--color-warning` | `#E37318` | 临期/待确认 |
| Color/Functional/Error | `--color-error` | `#D54941` | 取消/夜间单标 |
| Color/Bg/Page | `--bg-page` | `#F7F8FA` | 页面背景（暖灰，非纯白） |
| Color/Bg/Card | `--bg-card` | `#FFFFFF` | 卡片 |
| Color/Text/Primary | `--text-primary` | `#18191C` | 主文本 |
| Color/Text/Secondary | `--text-secondary` | `#86909C` | 次要文本 |
| Color/Text/Disabled | `--text-disabled` | `#C9CDD4` | 占位/禁用 |

**色彩比例（60-30-10）**：60% 暖灰背景与白卡（呼吸感）、30% 暖松绿（功能与信任）、10% 暖陶土+功能色（情绪点缀）。暖陶土全页出现不得超过 2 处。

### 3.2 字阶（rpx，微信小程序规范）

| Token | 值 | 用途 |
|---|---|---|
| Font/Display | 44rpx / 600 | 首页品牌名、C006 状态大标 |
| Font/Title | 32rpx / 600 | 卡片标题、价格 |
| Font/Body | 28rpx / 400 | 正文（行高 1.6） |
| Font/Caption | 24rpx / 400 | 辅助说明、时间戳 |
| Font/Tab | 20rpx / 400 | tabBar 文字 |

**字体戏剧性**：价格与金额是全页唯一允许"大而重"的元素（32-36rpx/600），与轻量正文形成对比——信任来自"数字清清楚楚"。

### 3.3 间距 / 圆角 / 阴影 / 动效

| Token | 值 | 用途 |
|---|---|---|
| Spacing/S · M · L | 24 · 32 · 48rpx | 元素内 · 卡片间 · 区块间 |
| Radius/Card · Button · Tag | 24 · 48（胶囊） · 8rpx | 卡片 24rpx 是品牌识别（比通用 16 更柔） |
| Shadow/Card | 0 2px 8px rgba(0,0,0,0.06) | 唯一阴影层级，禁止深阴影 |
| Motion/Page | 300ms ease-out | 转场 |
| Motion/Breath | 2s infinite（opacity 0.5→1） | 仅时间线当前节点 |

## 4. 组件样式（9 页共用的 7 个组件）

### 4.1 主按钮（btn-primary）
- 尺寸：全宽 - 64rpx 边距，高 88rpx，圆角 48rpx（胶囊）
- 四态：默认 `#5B8C85/#FFF` · 按压 `#4A756E` · 禁用 `#B9CFCB` · 加载 左侧 spinner+"提交中"
- **规则**：每页最多 1 个主按钮；次操作一律文字按钮（`#5B8C85` 文字，无底）

### 4.2 卡片（card）
- 背景 `#FFFFFF`，圆角 24rpx，padding 28-32rpx，阴影见 Token；卡片间距 24rpx
- 内部行间距 8rpx 栅格；label 用 `#86909C` 24rpx，value 用 `#18191C` 28rpx

### 4.3 价格展示（price）
- 格式：`¥800` —— ¥ 24rpx + 数字 36rpx/600，色 `#5B8C85`
- **锁价标记**：金额后跟 20rpx 灰字版本号（如 `v20260905`）——透明承诺的视觉锚点

### 4.4 状态标签（tag）
- 尺寸：高 44rpx，padding 4rpx 16rpx，圆角 8rpx
- 映射：待确认 `#FFF3E8/#E37318` · 服务中 `#E8F7EE/#2BA471` · 已完成 `#F2F3F5/#666666` · 已取消 `#FDECEC/#D54941`

### 4.5 时间线（timeline，C006 核心）
- 左侧竖线 4rpx `#E7E7E7`；节点圆点 20rpx：完成 `#2BA471`、当前 `#5B8C85` + 2s 呼吸、未来 `#E7E7E7`
- 节点影像：128×128rpx 圆角 8rpx，一行最多 4 张 +「+N」；点击全屏预览

### 4.6 输入框（input）
- 高 88rpx，无边框设计（底部 1rpx `#E7E7E7` 分隔线）——善终表单要"柔和"；错误态红字提示置字段下方，不用红框（避免情绪刺激）

### 4.7 空态（empty）
- 不用灰色默认插图：文案有温度（"更多温情服务筹备中"/"预约后自动生成宠物档案"），配品牌色细线插画位

## 5. 逐页视觉规则（9 页）

### C001 首页
- 60-30-10：头图区（220rpx 高，暖松绿渐变 `#5B8C85→#4A756E`，品牌名+slogan 白字）60%；三承诺横卡 30%；10% 留白
- **反模板**：三承诺卡不等宽（1.2:1:1），避免机械对称；禁用图标堆砌，纯文字+细分隔线
- 底部「明码标价」常驻条与 C002 呼应

### C002/C003 价格表
- Tab 吸顶（选中：品牌色+底部 4rpx 短线，非通栏下划线——更克制）
- 卡片左对齐（**禁居中**——价格表是决策信息不是海报）；价格右对齐大号
- 每卡底部「选这个」mini 胶囊按钮；页面底部常驻「不加价承诺」条（品牌色底白字）

### C004 预约
- 分组表单（套餐确认/宠物信息/服务安排三卡）；**全程无悲情元素**
- 费用汇总 sticky 底条：金额 + 「提交预约」主按钮并排
- 提交成功页：品牌色大对勾 + 「已提交，30 分钟内确认」——不跳转保持安静

### C005/C006 订单
- 列表卡：订单号 600 字重 + 状态标签右对齐；已完成列表置灰但可点
- C006 时间线影像是**信任巅峰**：影像不压缩质量、全屏预览白底、无水印——"敢给你看"的视觉表达

### C007 纪念品
- 双列网格卡：暖陶土仅用于价格数字；「预留/购买」用描边按钮（不用实心——弱推销）
- 空态文案「更多温情服务筹备中」

### C008/C009/C010
- 寄存查询：验证前页面极简（一个输入+一个按钮）；结果卡临期黄/到期红
- 宠物档案：宠物名+种类标签（品牌色浅底）；历史记录虚线分隔
- 个人中心：标准列表 + 头部品牌宣言「爱意小满，不留遗憾」

## 9. 精致化设计补充规范（2026-09-05 优化版）

> 本次基于 C001–C012 全量页面的视觉走查，对原型进行精致化校准后沉淀的补充规则，与 §3 Token 并行使用。

### 9.1 全局页面底色

- 所有 C 端页面背景统一为 `--bg-page` `#F7F8FA`（暖灰），禁止再使用偏黄/偏青的近似色。
- 内容卡片统一在 414px 宽画布中水平居中，内容区宽度 382px（左右各 16px 边距）。

### 9.2 导航区 / 状态头

- 顶部导航区统一使用暖松绿线性渐变 `#5B8C85 → #4A756E`，高度 96px。
- 状态栏文字与标题文字均为白色；标题 17px/600。
- 含大标题的状态头（如 C006）同样使用上述渐变。

### 9.3 卡片

- 所有信息卡片统一圆角 24rpx，阴影 `0 2px 8px rgba(0,0,0,0.06)`。
- 卡片内边距统一 20px，卡片之间间距 16px。
- 列表类卡片（订单、宠物档案）内行高改为 hug contents，关键信息行使用 `SPACE_BETWEEN` 两端对齐。

### 9.4 按钮

- 主按钮：宽度填满内容区，高度 56px，圆角 28px（胶囊），填充 `#5B8C85`，文字 16px/600 白色。
- 次按钮 / 描边按钮：高度 48px，圆角 24px，1px `#5B8C85` 描边，白色底，文字品牌色。
- 每页主按钮不超过 1 个。

### 9.5 Tab 选中态

- Tab 选中态统一为：品牌色文字 + 底部 3px/20px 宽的短横线指示器。
- 未选中态文字使用 `--text-secondary` `#86909C`，无指示器。

### 9.6 价格数字

- 价格数字为全页最重视觉元素：金额数字 24px/600，颜色 `#5B8C85`。
- 价格行统一右对齐，与服务名称形成左-右对比。

### 9.7 页面布局节奏

- 删除大段 `fill_container` 弹性空白，改用统一的 16px/24px `gap` 控制节奏。
- 底部固定元素（TabBar、汇总条）使用 absolute 定位，不与内容流争用空间。

### 9.8 首页特殊规范
