# 宠小满 C 端 / B 端趋势化 UI 升级记录 v1.0

> 执行日期：2026-09-15  
> 设计方向：温和疗愈型轻奢 + 原生平台感 + Expressive 核心操作 + Editorial 情绪叙事 + Quiet Operations 工作台

## 一、设计裁决

本轮不追求整套 Liquid Glass 或纯 Material 3 Expressive，而是把行业趋势转成宠物善终场景可用的设计语言：

- C 端优先建立安全感、价格透明和流程可见性。
- B 端优先建立待办优先、信息可扫描和状态可执行性。
- 多门店换肤只替换品牌 Token、Logo、店名、标语和内容，不改变交互结构。
- 渐变、装饰性光晕和过度浮层收敛为局部状态表达，避免影响文字对比度与核心任务。
- 主按钮采用明确的实心色块，卡片改为浅边框和轻阴影，减少“卡片套卡片”的视觉噪音。

## 二、本轮落地范围

### C 端小程序

- 全局页面背景改为稳定纸感底色，减少大面积渐变。
- 主按钮、登录按钮、价格选择按钮改为更接近原生控件的中等圆角实心按钮。
- 首页、价格表、订单、商品、个人中心、服务详情、承诺页、收银台、订单详情等页面统一主色头部与卡片边界。
- 保留品牌主色动态换肤、暖陶土提醒色、影像时间线和固定操作栏。
- 保留骨架屏渐变，因为它承担加载反馈，不属于装饰性主视觉。

### B 端后台

- 工作区由“纸感渐变”调整为更安静的中性页面底色。
- 统计卡增加轻量状态线，取消装饰性圆形光晕。
- 表格表头、筛选区、抽屉和空态统一使用明确表面层级。
- 工作台四条订单泳道使用不同状态色顶线，增强扫描和优先级识别。
- 登录页升级为“工作台语境 + 登录操作”的双栏结构，小屏自动收为单列。

## 三、组件验收口径

| 组件 | 验收重点 |
|---|---|
| 主按钮 | 默认、按压、禁用、加载状态清楚；文字不换行 |
| 卡片 | 内容区、边界、分组清晰；不依赖强阴影区分层级 |
| 表格 | 表头弱化但可读；金额数字右对齐；行悬停反馈明确 |
| 空态 | 说明为什么为空，并告诉用户下一步动作 |
| 错误态 | 说明发生了什么，并提供重试入口 |
| 固定操作栏 | 不遮挡明码标价、金额和主要字段；内容预留底部空间 |
| 白标换肤 | 主色变更后按钮、选中态、头部、导航同步变化，不出现品牌残留 |
