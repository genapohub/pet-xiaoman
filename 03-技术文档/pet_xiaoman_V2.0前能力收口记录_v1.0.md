## 三、三方配置位

### 支付

| 配置 | 说明 |
|---|---|
| `PAY_ENABLED` | 支付总开关，默认 `false` |
| `WX_APPID` | 小程序 AppID |
| `WX_MCH_ID` | 微信支付商户号 |
| `WX_PAY_SERIAL_NO` | 商户证书序列号 |
| `WX_PAY_NOTIFY_URL` | 支付回调地址 |
| `WX_PAY_PRIVATE_KEY` / `WX_PAY_PRIVATE_KEY_PATH` | 商户私钥 |
| `WX_PAY_API_V3_KEY` | API v3 密钥 |
| `WX_PAY_PLATFORM_CERT_PATH` | 微信支付平台证书 |

### 订阅消息

| 配置 | 说明 |
|---|---|
| `SUBSCRIBE_TEMPLATE_IDS` | 逗号分隔模板 ID；为空时小程序提示“以订单时间线为准” |

### 地图/定位

| 配置 | 说明 |
|---|---|
| `MAP_PROVIDER` | `wechat` / `tencent` / `manual` |
| `MAP_PICKER_ENABLED` | 是否启用位置选择；关闭后小程序引导手填 |
| `MAP_KEY` | 地图服务 key，仅后端/构建侧保存，不下发明文 |

小程序独立门店发布配置同样支持：

```bash
MAP_PROVIDER=wechat
MAP_PICKER_ENABLED=true
MAP_KEY=
node scripts/build-store-config.js
```

## 四、接口变更

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/c/integrations/config` | C 端读取支付、订阅、地图状态；不返回密钥 |
| GET | `/api/b/refunds` | 后台退款任务列表，默认看“退款中” |
| POST | `/api/b/orders/{order_no}/refund/mark` | 标记退款为“已退款”或“退款失败” |
