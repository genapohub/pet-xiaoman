# pet_xiaoman · 线上 VI 应用规格

> 版本 v1.0 · 2026-09-05 · graphic-design-guide（第二轮 2/4）
> 获客主战场小红书优先。全部数字物料：RGB/HEX、72 PPI、PNG（透明底场景）或 JPG（实底场景）。

## 一、小程序端

| 应用 | 尺寸(px) | 规范 |
|---|---|---|
| 小程序头像 | 144×144（上传建议 400×400 源图） | 纸感白底 `#FAF9F6` + 图形标（将满的圆，主绿线条）居中占高 60%；圆角由微信裁切，设计时按正方形无圆角交付 |
| 小程序 capsule 场景页头 | 375×150 设计稿 | 暖松绿**线性渐变** `#5B8C85→#4A756E`（§9.2）+ 反白文字标，右让位 88px（胶囊按钮） |
| 分享卡片 | 5:4 比例（500×400） | 左文右图：左侧 slogan + 承诺条，右侧暖陶土色块 + 图形标 |
| favicon（网页） | 16/32/48 | 图形标单色深松版 |

## 二、小红书（获客主战场，三套模板）

### 模板 A · 账号头像

| 项 | 规格 |
|---|---|
| 尺寸 | 400×400（显示为圆形，四角内容会被裁） |
| 构成 | 暖松绿 `#5B8C85` 实底 + 反白图形标居中占高 55% |
| 禁忌 | 不得用文字标（缩到圆形内不可读）——**图形标独占** |

### 模板 B · 笔记封面竖版（主用，3:4）

| 项 | 规格 |
|---|---|
| 尺寸 | 1242×1656（3:4） |
| 构图 | 纸感白底，留白率 ≥40%；标题（霞鹜文楷 Bold，占上 1/3，左对齐，字距 -3%）；配图区下 2/3；右下角图形标小样（高 64px）+「宠小满」小字 |
| 标题配色 | 深炭 `#3B3F45`；关键词可用暖松绿下划线标记（禁整句变色） |
| 内容系列 | 三幕故事对应三套封面骨架：①相遇（告别-宠物名系列，对齐竞品已验证打法）②同行（过程透明系列：价格章/影像截图）③小满（纪念与科普系列） |

### 模板 C · 笔记封面横版/图文内页

| 项 | 规格 |
|---|---|
| 横版封面 | 1242×830（3:2） |
| 内页配图 | 1242×1656 或 1080×1440；正文阿里普惠，行高 1.7，页边距 ≥8% |

|---|---|---|

| 微信公众号头像（未来） | 400×400 | 同小红书模板 A |
| 视频片头标（未来迭代） | — | 未启动 |

## 四、通用交付规则

- 文件命名：`chongxiaoman_小红书头像_400x400_v1.png`
- 全部提供：@2x 导出 + 源文件（SVG/Figma）
- 图形标最小可读尺寸：24px（低于此只用单色圆标）
- 上线前数字观感校对：手机实机查看（模拟器色彩偏亮）
