## 二、logo 使用规范（方向 A「将满的圆」已确认）

- **构成**：137° 缺口圆（有机线宽 3:2）+ 缺口处抽象三趾爪印；文字标「宠小满」圆头定制字，"满"字三点水 = 三枚渐小爪印点
- **三版本**：组合横版（默认）/ 图形标（头像/favicon）/ 反白单色版（深色底）
- **安全区**：四周 ≥ 图形高度 1/2；**最小尺寸**：图形标 16px、组合标宽 120px
- **色彩**：深松 `#3D5C57` 线条（白底）/ 反白（绿底）；爪印点缀陶土 `#D9A468`

### 禁止示例（六条，出现即返工）

| # | 禁止 | 原因 |
|---|---|---|
| 1 | 拉伸/压缩变形 | 破坏将满的圆比例，缺口角度变形 |
| 2 | 加投影/描边/渐变/发光 | 自然有机线拒绝特效，安宁感来自克制 |
| 3 | 放在低对比背景（绿上绿/花底） | 识别度坍塌 |
| 4 | 用云/星/彩虹元素替代或装饰爪印 | 竞品意象撞车（调研 F1） |
| 5 | 把缺口补圆、把爪印居中 | "满而不盈"的哲学就是缺口与偏心，补全=品牌死亡 |
| 6 | 改用宋体/书法体做文字标 | 传统殡葬庄重感错位（个性排除项） |

## 三、色彩速查（详见色彩体系 v1.0）

```
主色 暖松绿 #5B8C85（识别/操作）  深松 #3D5C57（文字/线条）
导航渐变 #5B8C85 → #4A756E（顶部导航/状态头专用，设计规范 §9.2）
辅色 暖陶土 #D9A468（情绪刺点 ≤10%）
底色 纸感白 #FAF9F6（60% 呼吸）   文字 深炭 #3B3F45（禁纯黑）
```

**五禁忌**：纯黑 / 冷蓝 / 促销红 / 荧光绿 / 紫色系。
