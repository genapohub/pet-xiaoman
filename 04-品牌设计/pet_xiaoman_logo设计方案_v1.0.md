# pet_xiaoman · logo 设计方案（方向稿）

> 版本 v1.0 · 2026-09-05 · graphic-design-guide（场景一裁剪版，第一轮 3/4 · **本轮需哥拿坡确认方向后进精稿**）
> 气质线：自然有机（MUJI 参照系）· 品牌个性：温暖/安宁/坦诚/恰到好处

## 一、设计命题

为「宠小满」三个字找一个**独占的自然符号**：它必须同时说三件事——宠物（爪印/尾巴）、小满（节气，将满未满）、告别（安宁不留遗憾）。禁用云/星/归（竞品已占），禁用黑白灰（行业雷区），禁用萌系卡通（与告别场景张力）。

**核心创意支点：小满的哲学是「满而不盈」——最好的告别，不是圆满，是将满未满。** 这个哲学可以几何化：一个**不闭合的圆**。圆是"满"，缺口是"小"和"留"——留白给遗憾，也留一个口子让爱继续。

## 二、三个方向候选

### 方向 A：将满的圆（推荐 ⭐）

- **构成**：一个缺口圆（缺口角度约 137°，黄金角度，刻意偏离整数角度），缺口处置一枚极简爪印（三趾抽象化，占圆内空间约 25%）。爪印朝向缺口——"从缺口走出去，也从这个口子被记得"。
- **线条**：圆用有机粗细变化的手绘感线条（笔画宽度 3:2 微差，非等宽），锚点禁止整数坐标。
- **文字标**：「宠小满」三字圆润无衬线体（定制基于思源黑体改造：笔画末端做 2-3° 圆头处理，"满"字三点水偏旁替换为三枚渐小的爪印点——**品牌独占记忆点**）。
- **为什么推荐**：哲学独占性最强（满而不盈只有小满能讲）、元素最少（圆+爪印，放大到 16px favicon 仍清晰）、遮住文字仍可识别。
- **风险**：抽象度高，需要一轮受众测试（小红书粉丝投票——竞品云伴的 logo 投票帖已验证此互动有效）。

### 方向 B：麦穗尾

- **构成**：一枝麦穗的穗粒排列成上扬摇尾的曲线（麦穗=小满物候 × 摇尾=宠物的告别姿态），穗尖一点陶土色。
- **气质**：更有生命感和温度，插画感强于方向 A。
- **风险**：图形复杂度高，小尺寸（favicon）细节易糊；与农业品牌意象有混淆可能。

### 方向 C：掌心小满

- **构成**：极简掌心线条向上托起一枚将满的圆（掌心=照护，圆=圆满告别）。
- **气质**：服务感最强，直白易懂。
- **风险**："手托物"是服务行业高频符号（保险/医疗/公益），独占性弱——**列为备选不推荐主推**。

### 三方向对比

| 维度 | A 将满的圆 | B 麦穗尾 | C 掌心小满 |
|---|---|---|---|
| 哲学独占性 | ★★★ | ★★ | ★ |
| 小尺寸适配 | ★★★ | ★★ | ★★ |
| 情感温度 | ★★ | ★★★ | ★★★ |
| 与竞品区分度 | ★★★ | ★★ | ★ |
| **建议** | **主推** | 备选 | 不推荐 |

## 三、规格定义（以方向 A 为例，确认方向后精稿遵循）

| 项 | 规格 |
|---|---|
| 主标组合 | 图形标（左）+ 文字标「宠小满」（右），横版；间距 = 图形宽度的 1/4 |
| 竖版/图标标 | 图形标单独使用；文字标竖排仅用于小红书头像 |
| 安全区 | 图形标四周留白 ≥ 图形高度的 1/2 |
| 最小尺寸 | 图形标 16px（favicon）；组合标宽 120px；小于此用图标标 |
| 反白版本 | 白色线条版（用于主绿底色）；单色深松版（用于黑白打印场景） |
| 主色应用 | 线条默认深松 #3D5C57；主绿底反白；陶土色仅用于爪印点缀（占比 <10%） |
| 禁止 | 拉伸变形、加投影/描边/渐变、放在花哨背景、改用云/星等其他元素替代爪印 |

## 四、反AI视觉八条对照

| 条款 | 本方案对应 |
|---|---|
| 1 禁完美几何 | 缺口角 137°（非整数）；线条粗细 3:2 手工差；精稿阶段锚点做黄金分割偏移 |
| 2 颜色侵略性 | 深松绿不是"环保绿"——它是偏灰的沉静绿（情绪任务：安宁的陪伴者），陶土是刺点（温暖的一次触摸） |
| 3 排版态度 | 文艺自然系：标题字距 -5%、行高 1.7、留白 45% |
| 5 构图侵略性 | 爪印偏心放置（非正中），负空间即缺口 |
| 7 文化符号语境 | 小满不是贴纸——"满而不盈"直接决定了圆的缺口形态，去掉哲学缺口就不成立，符号不可替换 |
| 8 留白是武器 | 头像/封面留白率 ≥40%（安宁感的量化表达） |

## 五、交付节奏

方向确认后 → 精稿（SVG 三版本：图形标/组合横版/组合竖版 + 反白单色）→ 线上应用 mock（头像/封面）→ 进第二轮（字体/线上 VI 规格）。

## 去AI味自检
- ✅ 不做决策：不做萌系卡通、不做云/星、C 方向明知好懂但主动降级（独占性不足）——三处取舍都有业务理由
- ✅ 数字具体：缺口 137°、爪印占比 25%、最小 16px、安全区 1/2 高、留白 ≥40%
- ✅ 竞品立场：云/星被竞品名字占用故禁止；文艺风继承"自然"避让"意象撞车"；云伴的投票互动被转化为方向测试方法
- ✅ 此刻合理性：小红书起号在即，头像/封面是第一批需要 logo 的场景，方向先定才能不返工
- ✅ 优先级倾斜：方向 A 主推（哲学独占性>情感温度>易懂性），C 方向主动标注不推荐
