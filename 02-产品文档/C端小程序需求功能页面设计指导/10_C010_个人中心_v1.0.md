```
页面（底 #F7F8FA，tab「我的」）

```

## ④ 异常场景

| 异常 | 表现 | 处理 |
|---|---|---|
| 身份未注册 | 编号区显示「未注册」 | onLaunch 已兜底重试；不阻塞浏览 |
| 菜单跳转目标页异常 | 目标页自身异常处理 | 本页不拦截 |

## ⑤ 视觉约束

- 品牌头是 slogan 的收尾触达位——文案与 theme.js 同源，禁硬编码第二份
- 菜单项**不加图标**（五项纯文字，留白即高级；图标会引入一套图标资产的维护成本，二期统一设计时再上）
- 「关于我们的承诺」已升级为详情页：明码标价 / 单独火化 / 过程可见 / 价格透明声明
- **§9 精致化**：卡片/按钮/Tab/价格规格统一按 00 总览 §2.3 精致化版执行（冲突时以 §9 为准）
