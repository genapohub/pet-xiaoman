## 二、视觉总纲（品牌体系 → rpx 落地映射）

> 来源：色彩体系 v1.0 / 字体体系 v1.0 / PRD §5.6.3。全端唯一真相，页面级文档不得另立色值。

### 2.0 多门店白标口径

- 默认示例门店：`宠小满·示例门店`，slug=`chongxiaoman`，使用宠小满品牌 UI（主色 `#5B8C85`、标语「爱意小满，不留遗憾」）。
- 顾客扫码进入：小程序从 `query.slug` 或扫码 `scene` 解析门店标识，拉取 `/api/c/store/profile?slug=xxx`，并保存 `store_slug`。
- 后续业务接口：统一带 `X-Store-Slug`，后端据此切到对应门店数据。
- 未配置 logo 的租户：显示店名首字占位，不回落到宠小满 logo，避免品牌串用。

### 2.3 间距 / 圆角 / 按钮

| 令牌 | 值（设计画布 414px 口径，§9 精致化版） | 说明 |

## 三、通用交互规范（全页面共享，页面文档不重复写）

| 场景 | 规范 |
|---|---|
| 加载 | 首屏：文字 tip「加载中...」居中（一期不做骨架屏，二期升级）；操作：按钮 loading 态禁重复点击 |
| 请求失败 | Toast「网络异常，请稍后重试」+ 保留页面可重试（列表页下拉刷新即为重试） |
| 空态 | 每页空态文案见各页异常表；空态禁白屏 |
| 401 | 清除 token/customer_id → 静默重登录 → 自动重放请求（request.js 已实现） |
| Toast | 单条、icon: none、时长 2s；成功用 icon: success |
| 触达 | 订阅消息在 C006 首次进入时请求一次，拒绝不再弹 |
| 布局节奏 | 禁大段弹性空白，统一 16/24px gap；底部固定元素 absolute 定位（§9.7） |
| 价格数字 | 24px/600 主绿右对齐——全页最重视觉元素（§9.6） |

## 四、本文件夹的维护规则

1. 改页面先改本文档（对应页五维），再改代码——文档是设计基线
2. 新增页面按同结构新增文档并更新 §一索引
3. 色值/字号变更必须先改 §二总览（品牌体系同步），再落到页面
