# pet_xiaoman_V1.0试运营清单_v1.0

> 日期：2026-09-13  
> 阶段：多租户白标 MVP / V1.0 试运营候选版  
> 目标：停止继续扩模块，把当前系统推进到真实门店可试运营状态。

---

## 一、结论

宠小满当前不是 V2.0，而是 **多租户白标 MVP / V1.0 试运营候选版**。

V1.0 的核心不是再做更多平台化能力，而是证明一件事：

> 1 家真实门店，能用这套系统稳定完成接单、履约、交付、回访。

---

## 二、V1.0 试运营目标

| 目标 | 验收口径 |
|---|---|
| 本地能稳定启动 | API、后台、小程序均可启动，主页面无阻断错误 |
| 真实门店资料可落库 | 店名、logo、主色、电话、地址、营业时间、价格、商品、账号完整 |
| C 端入口可用 | 扫码 slug / 独立 AppID 默认 slug 均能进入对应门店品牌 |
| 后台履约可用 | 店长/店员能登录并完成订单流转 |
| 完整订单跑通 | 预约、确认、接宠、服务中、影像、交付、完成全链路闭环 |
| 提审材料可准备 | 类目、协议、隐私政策、价格声明、中性文案清单齐备 |

---

## 三、V1.0 范围

### P0 必须完成

| 模块 | 任务 | 产出 |
|---|---|---|
| 启动与冒烟 | PyCharm 启动 API、后台前端，小程序开发者工具联调 | 冒烟记录 |
| 平台超管 | 开真实门店、配品牌、配小程序入口、开店长账号 | 真实门店资料就绪 |
| C 端 | 首页、价格、下单、订单、个人中心、承诺页完整跑一遍 | C 端体验可用 |
| B 端 | 今日工作台、订单、服务项目、商品、客户、寄存、员工权限跑一遍 | 门店后台可用 |
| 多租户 | 至少两家门店数据隔离验证 | 无串店 |
| 订单履约 | 跑 1 笔完整订单 | 主流程闭环 |
| 合规材料 | 小程序类目、协议、隐私、价格声明、中性文案 | 提审材料包 |

### P1 试运营后补强

| 模块 | 任务 | 说明 |
|---|---|---|
| 异常履约 | 取消原因、改期约束、弱网影像补传 | 根据真实使用卡点补 |
| 订阅消息 | 从配置可用推进到真实提醒有效 | 需要模板 ID 与真机验证 |
| 回访任务 | 订单完成后形成回访闭环 | 服务口碑与转介绍抓手 |
| 数据记录 | 记录来源渠道、加购、客单价 | 为 V1.5 经营分析做准备 |

### V1.0 明确不做

- 不做平台跨店经营看板。
- 不做租户自助入驻。
- 不做复杂装修系统。
- 不做平台订阅收费。
- 不把微信支付作为 V1.0 阻塞项；商户号未就绪时继续到店付。

## 五、V1.0 试运营指标

| 指标 | 目标 | 用途 |
|---|---:|---|
| 主流程人工跑通率 | 100% | 判断是否可进入试运营 |
| 首批真实订单 | 10 单 | 判断是否进入 V1.5 |
| 影像节点覆盖率 | 接近 100% | 验证过程透明承诺 |
| 小程序预约占比 | 逐步达到 60% | 判断线上化价值 |
| 加购率 | 先记录基线 | 判断纪念品/寄存价值 |
